# Online Zakat Payment Management System

A web-based Zakat Management System developed using Next.js, Node.js, and MySQL.

## Features

- User Authentication
- Zakat Payment Management
- Beneficiary Management
- Reports Dashboard
- Admin Panel

## Technologies Used

- Next.js
- React.js
- Node.js
- MySQL
- Prisma ORM
- Tailwind CSS

## Installation

1. Install Node.js
2. Install XAMPP
3. Create MySQL database
4. Configure .env file
5. Run:

```bash
npm install
npm run dev
```

## Default URL

http://localhost:3000
